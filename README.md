# 随意搭 · 重构版

**`main` 上的默认首页 `/` 就是重构版，不是原版。** 重构版采用双女孩复古漫画插画，首页标题为“今天穿什么？穿成你喜欢的样子。”原版只保留在 `/legacy`，供对比查看。

## 用 Codex 打开与启动

1. 在 Codex 中打开本仓库根目录，先检查 `git status`，保留已有改动。确认当前分支和远程 `main`，不要使用旧检出或直接覆盖本地工作。
2. 在根目录执行：

   ```bash
   npm install
   npm run dev
   ```

   根目录命令会转到 `随意搭/` 中的新版应用；安装时也会安装该应用的锁定依赖，无需猜测启动目录。
3. 打开终端实际输出的地址，默认是 <http://127.0.0.1:3000/>。如果 3000 被旧进程占用，Next.js 可能使用其他端口；先确认占用者，不要一边启动新版本、一边打开旧进程的地址。
4. 确认首页显示双女孩漫画及上述新版标题。`/upgrade` 是升级说明和 Codex 教程，不是产品首页；`/legacy` 是旧版，不应设为默认入口。

可把下面这段直接发给接手的 Codex：

> 请先读根目录 AGENTS.md、README.md 和“随意搭/README.md”。保留本地改动，核对当前分支与远程 main；从根目录启动当前重构版，并用浏览器打开实际运行端口的 `/`。新版首页应显示“今天穿什么？穿成你喜欢的样子。”和两个复古漫画女孩。不要打开 `/legacy`、历史提交或旧开发进程；不要把 `/upgrade` 当作产品首页。如果发现不是新版，先核对提交、进程工作目录和端口，再修复。

## 页面与验收

- `/`：重构版产品首页。
- `/legacy`：原版对比，提供返回新版入口。
- `/upgrade`：升级说明、产品方法和 Codex 七步教程。

从根目录执行 `npm test`、`npm run typecheck`、`npm run lint`、`npm run build`。服务器启动后运行 `npm run test:entrypoints`，检查默认首页是新版且旧版对比仍可访问；若端口不同，使用 `npm run test:entrypoints -- http://127.0.0.1:3001`。

完整功能、本地数据及模拟能力说明见 [应用 README](./随意搭/README.md)。这些命令不负责部署；Git 推送和线上部署是两个独立动作。
